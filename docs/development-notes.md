# Изменения в 0.3.6

Включены в обновление 0.3.6 для Arch, Debian/Ubuntu и Windows 11 x64.

- Ctrl+V вне поля ввода добавляет ссылку подписки. Обычная вставка в текстовые поля не перехватывается.
- Название, объявление, лимиты и интервал подписки читаются из HTTP-заголовков и `#`-метаданных тела; заголовки имеют приоритет.
- JSON и описания серверов разбираются из исходного ответа. Удалён скрытый повторный запрос от имени Happ. Подписки запрашиваются с `User-Agent: NORY/<версия>` и `Accept: application/json, text/plain;q=0.9`; HWID передаётся только при включённом переключателе. Если провайдер выдаёт JSON только определённым клиентам, ему нужно добавить поддержку NORY.
- Описания контрастнее, без обрезания до двух строк. Объявление провайдера видно и при свёрнутых серверах.
- В настройках доступны ICMP, TCP и прокси-пинг. ICMP/TCP показывают доступность узла или CDN, а не работоспособность VPN. Прокси-пинг проверяет HTTPS с ответом 204 через профиль, включая протокол и TLS. Все типы делают пять запросов; без успешных ответов — `n/a`.
- Проверки привязываются к внешнему IPv4-интерфейсу, а не активному TUN. DNS для ICMP/TCP разрешается отдельно через этот интерфейс. Если такой маршрут определить нельзя, проверка завершается ошибкой — возврата к пингу через VPN нет. IPv6-only подключения пока не поддерживаются этим способом проверки.
- Для прокси-пинга запускаются изолированные ядра с локальными SOCKS-входами, **без TUN и без системных маршрутов**; одновременно не более двух. Прямые правила и DIRECT-fallback не должны превращать недоступный прокси в успешную проверку. Закрытие диагностического процесса не затрагивает активное VPN-подключение.
- Для GeoSite/GeoIP проверяется наличие категорий в бинарных `.dat`. В настройках можно указать HTTPS-источник провайдера; поддерживаются также `geosite-url`/`geoip-url` в подписке и `Geositeurl`/`Geoipurl` в JSON. Неизвестные правила не удаляются автоматически.
- Для отсутствующего `geosite:torrent` используется отдельная категория из компактной roscomvpn GeoData с закреплёнными ревизией и SHA-256. Остальные категории установленной базы не заменяются. Указанный пользователем или провайдером источник имеет приоритет; отсутствие категории в нём является ошибкой.

Проверены сборка фронтенда, Rust/Tauri на Linux, компиляционная проверка Windows-бэкенда, прямые сетевые запросы на Linux и принятие конфигурации `geosite:torrent` установленным Xray. Это не заменяет проверку реального TUN на Windows 11 и соединения с конкретным провайдером.

Форматы метаданных: [документация Happ](https://github.com/HappDev/happ_su/blob/main/dev-docs/app-management.md). GeoData и маршрутизация: [документация Xray](https://xtls.github.io/en/config/routing), [источник дополнительной категории](https://github.com/hydraponique/roscomvpn-geosite).
