# NORY 0.4.0

Полная замена прежнего WebView-интерфейса нативными приложениями: SwiftUI / AppKit на macOS, WinUI 3 на Windows и GTK4 / libadwaita на Linux.

- Тёмная тема без переключателя и системные кнопки окна.
- Liquid Glass на macOS, Desktop Acrylic на Windows и матовые панели на Linux.
- Плавающая нижняя навигация, компактный список серверов и режим карточек.
- В Windows список прокручивается под навигацией без отдельной нижней полосы; последний элемент можно поднять выше панели.
- Круглые флаги; сохранены описания подписок и серверов.
- Обновлены меню, поля ввода и кнопки Mac-интерфейса.
- Mihomo больше не входит ни в одну сборку. Для подключения используются Xray и sing-box TUN.
- При подключении сохраняются маршрутизация, DNS, outbounds и балансировщики из Xray JSON выбранного сервера.
- Исправлен путь автозапуска Linux для нового нативного клиента.
- Обновлены установщики и подпись манифестов обновлений Windows / Linux.

Переход с 0.3.x выполняется ручной установкой нового пакета. macOS обновляется вручную. Приложения Android и iOS пока не выпущены.
