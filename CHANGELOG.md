# NORY 0.4.4 · Windows · 2 октября 2026

- Принудительное завершение sing-box заменено штатным сигналом остановки с запасным завершением при зависании.
- Исправлен порядок очистки: маршруты снимаются до ожидания, оставшееся устройство TUN удаляется по идентификатору.
- Добавлено восстановление адаптеров старых версий NORY. Совпадение имени, типа драйвера и PnP-идентификатора дополняется эксклюзивным открытием сессии Wintun; устройство, занятое другим процессом, не удаляется.
- Увеличено время ожидания старой службы в установщике.

Windows-сборка без автотестов и запуска VPN. Результат на устройстве пользователя ещё не подтверждён. macOS и Linux остаются на 0.4.1; ключ подписи обновлений прежний.

# NORY 0.4.3 · Windows · 2 октября 2026

- Служебный DNS TUN переведён на HTTPS через Xray: устранён конфликт порта 53 со строгой маршрутизацией Windows при `direct` в JSON.
- При переключении сервера служба ожидает освобождения своего Wintun-адаптера.
- Подключение и отключение выполняются последовательно; быстрые нажатия не накапливают запуски. Старые ответы опроса не перезаписывают новый статус.
- Флаги загружаются из встроенных PNG и обрезаются по кругу.
- Убрана заливка кнопок нижней навигации.
- JSON сервера открывается в отдельном окне с форматированием, прокруткой, переносом строк, копированием и сохранением.

macOS и Linux остаются на 0.4.1. Ключ подписи обновлений не изменён. Сборка без автотестов, проверки интерфейса и запуска реального VPN; устранение задержки на подключении пользователя ещё не подтверждено.

# NORY 0.4.1 · 2 октября 2026

- Windows: исходящие соединения Xray привязаны к физическому сетевому адаптеру, чтобы не попадать обратно в TUN.
- Windows: DNS для адресов самих VPN-серверов разрешается отдельно от туннеля; остальные DNS-запросы продолжают использовать Xray и правила выбранного профиля.
- Windows: локальное соединение sing-box → Xray явно привязано к loopback; уточнено сообщение о выборе свободного имени адаптера.
- macOS и Linux: `TLS` отображается без ошибочного преобразования в `Tls`.
- Ключ подписи обновлений сохранён с 0.4.0.

Сборки опубликованы без автотестов, проверки интерфейса и запуска реального VPN.

# Исправленная Windows-сборка 0.4.0 · 2 октября 2026

- Устранено повторное использование кнопки питания при пересборке страницы: исправлен вылет при возврате на VPN и ошибка «Не обнаружено установленных компонентов» после подключения.
- Выбранные пункты нижней навигации используют нейтральную серую подсветку во всех состояниях нажатия и наведения.
- Ошибки отрисовки обрабатываются отдельно от VPN-операций; диагностика сохраняется локально в `%LOCALAPPDATA%\NORY\ui.log`.
- Ключ подписи обновлений 0.4.0 сохранён. Windows-сборки включают Xray, sing-box, Wintun и системный helper.

Заменены только Windows-пакеты в существующем релизе 0.4.0. Для установки исправлений скачайте EXE заново; номер версии не изменился.

# NORY 0.4.0

Полная замена прежнего WebView-интерфейса нативными приложениями: SwiftUI / AppKit на macOS, WinUI 3 на Windows и GTK4 / libadwaita на Linux.

- Тёмная тема без переключателя и системные кнопки окна.
- Liquid Glass на macOS, Desktop Acrylic на Windows и матовые панели на Linux.
- Плавающая нижняя навигация, компактный список серверов и режим карточек.
- В Windows список прокручивается под навигацией без отдельной нижней полосы; последний элемент можно поднять выше панели.
- Круглые флаги; сохранены описания подписок и серверов.
- Обновлены меню, поля ввода и кнопки Mac-интерфейса.
- Mihomo больше не входит ни в одну сборку. Для подключения используются Xray и sing-box TUN.
- При подключении сохраняются маршрутизация, DNS, outbounds и балансировщики из Xray JSON выбранного сервера.
- Исправлен путь автозапуска Linux для нового нативного клиента.
- Обновлены установщики и подпись манифестов обновлений Windows / Linux.

Переход с 0.3.x выполняется ручной установкой нового пакета. macOS обновляется вручную. Приложения Android и iOS пока не выпущены.
