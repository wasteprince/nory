## Новое в 0.3.3

Если провайдер передаёт узел как «Париж | …» без emoji, NORY определяет город
и показывает флаг в карточке выбранного сервера и в сетке. Linux использует
системный emoji-шрифт, Windows — встроенный PNG-набор.

## Новое в 0.3.2

Исправлен запуск TUN на Windows 11: отключённый Wintun-интерфейс теперь
переиспользуется, а готовность туннеля определяется по созданному интерфейсу,
не по временному состоянию драйвера. Это устраняет ситуацию «интерфейс есть,
но подключение не запускается».

В карточке выбранного сервера теперь всегда показывается его флаг — системный
в Linux и встроенный в Windows. Карточка получила более аккуратную иерархию,
мягкий фон и компактный акцент без изменения навигации Happ.

## Новое в 0.3.1

Интерфейс перенесён на **Vue 3, TypeScript и Tailwind CSS в Tauri 2**.
Подписки, HWID и управление ядрами остаются в Rust. Данные предыдущих версий сохраняются.

Исправлен вылет после открытия окна на NVIDIA + Wayland (`Error 71`):
совместимость explicit sync применяется автоматически. GPU-ускорение остаётся включённым.
Вместо системной шапки — собственная панель окна; выпадающие меню оформлены
в цветах приложения. Тёмная палитра по примеру Happ: почти чёрный фон,
графитовые карточки, серо-синий блок подключения и фиолетовые акценты.
Активный VPN остаётся зелёным. Меньше повторяющихся
подписей и рамок, счётчики объединены; шрифты и карточки серверов сохранены.
Первый показ окна отложен до готовности локального интерфейса, без ожидания
подписок или пинга; задан непрозрачный фон и убрано стартовое затухание страницы.
Исправлена обработка выключения во время запуска и после ошибки очистки TUN:
клиент сохраняет возможность повторить остановку и не возобновляет VPN после отмены.

Для Windows 11 используется WebView2 вместо старого GTK-runtime; флаги включены
в приложение только для Windows. Xray TUN запрашивает подтверждение администратора
через UAC на время работы клиента; интерфейс остаётся с обычными правами.
Все три канала — **arch, debian, windows** — получают стабильную версию 0.3.3.
[Особенности Windows и ограничения](WINDOWS.md).
Реальные VPN-соединения и работа TUN на настоящей Windows 11 в этом выпуске не тестировались.

## Просто подключиться

NORY — настольное приложение с Rust-бэкендом и локальным интерфейсом Tauri.
Добавьте подписку, выберите сервер и включите VPN.

- **Два TUN-режима:** Xray с sing-box или Mihomo. Ядра входят в пакеты; переключение останавливает предыдущий VPN-бэкенд.
- **Подписки:** несколько независимых подписок, HWID, описания серверов и обновление списка.
- **Конфигурации:** импорт Xray JSON и Mihomo JSON, преобразование поддерживаемых протоколов и балансировщиков между ядрами. Если есть конфигурации для обоих ядер, используются родные варианты. Возможности ядер различаются — не каждый параметр можно перенести без потерь.
- **Обход VPN:** выбор приложений и процессов, поиск по списку; встроенный обход России по GeoSite category-ru и GeoIP ru, выключенный по умолчанию.
- **Повседневные инструменты:** массовый ICMP-пинг, статистика трафика, трей, настройки и подробные логи.
- **Обновления из GitHub Releases:** подпись Ed25519, проверка размера и SHA-256 перед установкой.

## Установка

Скачайте пакет своей системы на [странице последнего релиза](https://github.com/wasteprince/nory/releases/latest).
Запускайте NORY из меню приложений, не от root; системные действия выполняются через отдельный helper.

| Система | Файл | Установка из папки с пакетом |
| --- | --- | --- |
| Arch Linux, x86_64 | `nory-…-x86_64.pkg.tar.zst` | `sudo pacman -U ./nory-0.3.3-1-x86_64.pkg.tar.zst` |
| Ubuntu 24.04+ / Debian 13+, amd64 | `nory_…_amd64.deb` | `sudo apt install ./nory_0.3.3_amd64.deb` |
| Windows 11 x64 | `NORY-0.3.3-windows-x64-setup.exe` | Запустить установщик |

Перед ручным обновлением закройте NORY через трей. Для Linux нужны systemd,
WebKitGTK 4.1, GTK3 и агент авторизации polkit. `.deb` требует glibc 2.39:
Debian 12 и Ubuntu 22.04 не поддерживаются. Windows-установщик проверяет WebView2;
если он отсутствует, загрузчик Microsoft установит его через интернет.
Установщик NORY без Authenticode; возможно предупреждение SmartScreen. macOS-сборки нет.

## Переход на GitHub

**0.2.25 — переходный релиз.** Установленные версии со старым источником обновлений получат его через прежний сервер. После установки NORY проверяет новые версии и скачивает пакеты только с GitHub.

Каналы **arch, debian, windows** остаются раздельными и подписываются прежним
Ed25519-ключом. Старый сервер сохраняется для перехода существующих клиентов,
но новых релизов после 0.2.25 там не будет. Архив старых версий на GitHub не переносится.
