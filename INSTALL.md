# Установка NORY

Сначала отключите VPN и полностью завершите предыдущую версию NORY. Для перехода с 0.3.x скачайте новый установщик вручную. Удалять подписки и настройки не требуется.

## Android

Требуется Android 8.0 или новее. [Универсальный APK 0.4.13](https://github.com/wasteprince/nory/releases/download/v0.4.15/NORY-0.4.15-android.apk) включает ARM64, ARMv7 и x86‑64.

1. Скачайте APK и откройте его. Если Android попросит, разрешите установку этому браузеру или файловому менеджеру.
2. В NORY нажмите «+» и вставьте ссылку на подписку, ключ сервера или полный JSON Xray.
3. Выберите сервер, нажмите кнопку подключения и подтвердите системный запрос VPN.

Root и отдельный helper не нужны. Разрешение VPN сохраняет Android; система может запросить его снова после отзыва разрешения или переключения на другой VPN-клиент. Отключить VPN можно в NORY или через системное уведомление.

«Роутинг» содержит тумблер обхода российских сайтов, список своих доменов и выбор приложений без VPN. При изменении правил активное подключение перезапускается. Содержимое исходного JSON доступно в сведениях о сервере.

В «Настройках» доступны разделы подключения, сети и DNS, проверки серверов, подписок, поведения приложения и дополнительных параметров. Изменение настроек сети перезапустит VPN. Периодические обновления подписок и переподключение работают, пока процесс NORY доступен Android.

HWID показан вверху «Настроек» и копируется кнопкой рядом. Он сохраняется при обновлении NORY. Отправку можно переключить при добавлении подписки или через её меню «…». Для существующих подписок отправка включена по умолчанию; настройка в разделе «Подписки и HWID» задаёт значение для новых источников. После обновления с 0.4.11 нажмите «Обновить подписки», чтобы провайдер получил HWID.

Подписки и настройки хранятся локально; резервное копирование Android отключено. Начиная с 0.4.15 NORY обновляется сам: «Настройки» → «NORY для Android» → «Обновить». Приложение скачивает APK с GitHub, проверяет SHA-256 и открывает установщик Android; при первом обновлении разрешите установку приложений для NORY. О новой версии NORY сообщает при запуске. Вручную новый APK устанавливается поверх старого, без удаления NORY. Сервис Always-on VPN и запуск после перезагрузки пока не поддерживаются.

## macOS

Требуется macOS 26 или новее. Выберите пакет по процессору: Apple Silicon (arm64, включая MacBook Neo) или Intel (x86_64).

1. Скачайте [PKG для Apple Silicon](https://github.com/wasteprince/nory/releases/download/v0.4.13/NORY-0.4.13-macos-arm64.pkg) или [PKG для Intel](https://github.com/wasteprince/nory/releases/download/v0.4.13/NORY-0.4.13-macos-x86_64.pkg).
2. Запустите установщик, затем откройте NORY из «Программ».
3. Добавьте подписку, выберите сервер и подключитесь.

Сборка имеет локальную ad-hoc подпись и не нотарифицирована Apple. Если macOS блокирует установщик, используйте разрешение на его открытие в «Системные настройки → Конфиденциальность и безопасность».

Системный компонент VPN запрашивает пароль администратора при установке или обновлении. Обычные повторные подключения используют установленный компонент. Открывать `nory-helper` отдельно не нужно. Системный диалог добавления VPN-конфигурации через Network Extension в этой версии не используется.

DMG и ZIP содержат то же приложение для ручного переноса в «Программы».

## Windows

Выберите установщик по архитектуре процессора:

- [Windows 11 x64](https://github.com/wasteprince/nory/releases/download/v0.4.14/NORY-0.4.14-windows-x64-setup.exe) — Intel и AMD.
- [Windows 11 ARM64](https://github.com/wasteprince/nory/releases/download/v0.4.14/NORY-0.4.14-windows-arm64-setup.exe) — ARM, включая Snapdragon.
- [Windows 10 x64](https://github.com/wasteprince/nory/releases/download/v0.4.14/NORY-0.4.14-windows10-x64-setup.exe) — 21H2, 22H2 и LTSC 2021 (сборка 19044 и новее).

Архитектура указана в «Параметры → Система → О системе → Тип системы». ARM64-пакет содержит нативные версии интерфейса, Xray, sing-box, Wintun и системного компонента VPN. Обновления разделены по архитектуре.

Windows 10 использует отдельную сборку и отдельный канал обновлений. Прозрачность и собственная полоса заголовка включаются, если их поддерживает система; при отключённых эффектах прозрачности и в удалённом рабочем столе окно остаётся непрозрачным. Значки Fluent используются, если шрифт Segoe Fluent Icons установлен, иначе — аналогичные значки Segoe MDL2 Assets.

Windows x86, Windows 10 ARM и Windows Server не поддерживаются.

### Если старая версия сообщает «подпись обновления не прошла проверку»

При переходе на 0.4.0 изменился ключ подписи обновлений. Прежний клиент не доверяет новой подписи, поэтому его встроенное обновление не может выполнить этот переход. Повторная проверка обновлений в старом клиенте это не исправит.

1. Отключите VPN и выберите «Выйти» в меню NORY в системном трее.
2. Скачайте установщик для своей версии Windows по ссылкам выше и запустите его вручную.
3. Откройте установленную NORY через меню «Пуск». Старый EXE из папки загрузок или старой переносимой копии больше не используйте.

Удалять пользовательские подписки и настройки не нужно. В 0.4.0 уже встроен ключ опубликованного манифеста; последующие обновления используют его. Это сообщение относится к подписи обновления внутри NORY, а не к Windows SmartScreen.

Начиная с 0.4.9 NORY выполняет штатное завершение TUN, удаление собственного адаптера и восстановление оставшихся устройств старых версий при следующем подключении. Отключите VPN и установите новый EXE поверх предыдущей версии. Если при включённом VPN интернет недоступен, сначала отключите его, затем скачайте обновление.

Если предыдущая версия не выходит из-за ошибки очистки TUN, завершите `nory.exe` через Диспетчер задач, затем запустите установщик своей архитектуры.

### Обычная установка

Запустите скачанный EXE для своей архитектуры. Установщик разместит приложение в Program Files и подготовит системный компонент TUN. Затем запускайте NORY обычным пользователем. .NET и Windows App SDK входят в комплект; библиотеки Visual C++ также включены в пакет; WebView2 больше не требуется.

Установщик не имеет коммерческой Authenticode-подписи. Для обычной установки используйте EXE. ZIP предназначен для ручного развёртывания и сам по себе не устанавливает службу TUN.

## Ubuntu / Debian · бета

[Пакет DEB 0.4.13](https://github.com/wasteprince/nory/releases/download/v0.4.13/nory_0.4.13_amd64.deb) для Ubuntu 24.04+ или Debian 13+.

Архитектура — amd64.

```sh
sudo apt install ./nory_0.4.13_amd64.deb
```

Откройте NORY через меню приложений. GTK4, libadwaita и Python устанавливаются пакетным менеджером. Для TUN используются systemd и polkit. Разрешение VPN запрашивается один раз на пользователя и сохраняется после перезагрузки и обновления NORY. Запускать графический интерфейс от root не нужно.

## Arch Linux · бета

[Пакет 0.4.13](https://github.com/wasteprince/nory/releases/download/v0.4.13/nory-0.4.13-1-x86_64.pkg.tar.zst)

```sh
sudo pacman -U ./nory-0.4.13-1-x86_64.pkg.tar.zst
```

## Обход сайтов и приложений

Откройте «Роутинг». В разделе сайтов нажмите «Добавить сайт» и введите домен или HTTP(S)-ссылку. Можно вставить несколько сайтов, по одному на строке. Правило распространяется на домен и его поддомены; путь страницы не учитывается. Для приложения выберите запись из каталога, запущенный процесс или исполняемый файл.

Правила сохраняются автоматически; активный VPN переподключается. Уже открытые соединения приложения могут потребовать его перезапуска. Сайт может обращаться к другим доменам — при необходимости добавьте их отдельно.

## Проверка файлов

В релизе опубликован `SHA256SUMS.txt`. Он содержит контрольные суммы установщиков, архивов, превью и манифестов обновлений.

Релиз 0.4.13 собран без запуска реального VPN на устройствах.
